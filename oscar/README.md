# Oscar Board Coach

En långsiktig, statisk coachsida för Oscars snowboard- och skateboardutveckling.

- Videofiler publiceras inte här.
- Nya filmer analyseras i ChatGPT och sammanfattas på sidan.
- Baslinje v1.0 bygger på 30 uppladdade klipp, 6 oktober 2026.
- Fokus: teknik, trickprogression, träning, tävlingsförberedelse och långsiktig utveckling mot Snowboardgymnasiet Malung.

## Uppdateringsprincip

Varje ny videosession ska resultera i:
1. samlad jämförelse mot tidigare nivå,
2. 1–3 prioriterade teknikpunkter,
3. trick som är redo nu,
4. nästa progression,
5. vad som ska filmas nästa gång.

Sidan är medvetet fri från själva videofilerna.
